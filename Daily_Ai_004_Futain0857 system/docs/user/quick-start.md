# 富田貨櫃出租系統 — 快速入門指南 (Quick Start Guide)

歡迎使用**富田貨櫃出租管理系統 v1.0.0**！本指南幫助您在 5 分鐘內了解系統基本架構並完成第一筆租賃合約操作。

---

## 🚀 1. 快速登入

1. 打開瀏覽器，造訪系統網址：`http://localhost:5173/` (或正式營運網址)。
2. 本機測試環境可直接點選金黃色按鈕 **「🚀 本機測試：點我一鍵快捷登入 (免密碼 - TEST/DEV ONLY)」** *(註：正式 Production 上線模式下此按鈕會自動隱藏，僅保留正式密碼登入區)*。
3. 正式環境請輸入您的管理員帳號與密碼，點選「確認登入系統」。

---

## 📦 2. 5 分鐘營運標準流程

### 步驟 A：建立客戶與貨櫃
- 導覽至 **客戶管理** ➔ 點選「新增客戶」，輸入姓名、電話與統一編號。
- 導覽至 **貨櫃管理** ➔ 點選「新增貨櫃」，輸入貨櫃編號 (如 `CONT-2001`)、尺寸 (20呎) 與存放區域。

### 步驟 B：建立與啟用租賃合約
- 導覽至 **租約與合約** ➔ 點選「建立新合約 (Wizard)」。
- 依照 6 步驟分步引導：
  1. 選擇承租客戶
  2. 選擇 1 個或多個空貨櫃
  3. 設定起租日與優惠月租金
  4. 設定押金與分期數
  5. 預覽合約與條款
  6. 點選「確認啟用合約」➔ 貨櫃將自動轉為 `RENTED (出租中)`。

### 步驟 C：應收對帳與登記收款
- 導覽至 **應收與對帳** ➔ 於右側表單選擇帳單。
- 輸入實收金額 (支援部分付款與全額結清)，選擇付款管道 (銀行轉帳 / 現金 / LINE Pay) ➔ 點選「登記入帳」。

### 步驟 D：合約續約與退租結算
- **續約**：於合約列表中點選「辦理續約」，保留舊合約歷史連動並自動建立新一期應收。
- **退租**：導覽至 **退租與結算** ➔ 開啟 7 步驟退租 Wizard，引導完成遙控器清點、押金扣抵試算與現場驗收解鎖，將貨櫃恢復為 `AVAILABLE (空櫃)`。

---

## 📥 3. CSV 報表匯出

於任何管理頁面（客戶、貨櫃、合約、應收對帳、營運支出），點選右上角 **「📥 匯出 CSV」** 按鈕，即可下載具備 UTF-8 BOM 前綴之 Excel 相容中文報表。
