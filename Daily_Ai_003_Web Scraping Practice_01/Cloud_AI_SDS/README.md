# Cloud AI Software Development Standard

## 版本資訊

- **Version:** v1.0
- **Status:** Draft
- **Last Update:** 2026-07-03

## 標準架構

```
Cloud_AI_SDS/
├── company/           # 公司級標準
│   ├── Company_Profile.md
│   ├── Development_Principles.md
│   ├── Coding_Standard.md
│   ├── Documentation_Standard.md
│   ├── AI_Collaboration_Standard.md
│   └── Review_Standard.md
├── templates/         # 文件範本
│   ├── Project_Template/
│   ├── SDD_Template/
│   ├── Requirement_Template/
│   ├── API_Template/
│   └── Database_Template/
└── examples/          # 應用範例
    └── PTT_Joke_Meme_PWA/
```

## 目的

建立 AI 輔助軟體開發的標準化流程，確保多 AI 協作時的一致性與品質。

## 使用方式

1. 新專案從 `templates/Project_Template/` 開始
2. 依 `company/` 標準撰寫程式碼與文件
3. 依 `templates/` 建立各類文件
4. 參考 `examples/` 了解實際應用
