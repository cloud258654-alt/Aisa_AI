## 1. 專案背景

### 1.1 專案名稱

PTT Joke Meme PWA

### 1.2 專案描述

一個 Progressive Web App，用於彙整 PTT Joke 板上有梗的貼文。使用者可以瀏覽、搜尋並分享附有圖片預覽的有趣貼文。

### 1.3 目標

以 MVP (Minimum Viable Product) 模式快速建立可用的梗圖瀏覽平台。

### 1.4 技術棧

| 層級 | 技術 | 負責 AI |
|------|------|---------|
| 後端 | Python (FastAPI) | OpenCode |
| 前端 | PWA (HTML/CSS/JS) | Gemini |
| 資料庫 | SQLite (MVP) | OpenCode |
| 爬蟲 | Python (requests + BeautifulSoup) | OpenCode |

## 2. 功能需求

### FR-001：定時爬取 PTT Joke 板

系統應能定期爬取 PTT Joke 板的最新貼文。

### FR-002：擷取貼文資料

系統應從每篇貼文中擷取標題、內容、圖片 URL 及文章連結。

### FR-003：儲存資料

系統應將擷取的資料存入資料庫，不下載圖片，僅儲存圖片 URL。

### FR-004：提供 REST API

系統應提供 REST API 供前端查詢已儲存的貼文。

### FR-005：顯示梗圖

系統應以 PWA 方式在行動裝置上友善顯示梗圖。

### FR-006：支援搜尋與篩選

系統應支援以關鍵字搜尋或篩選梗圖。

### FR-007：離線瀏覽

系統應支援離線存取已快取的貼文。

## 3. 非功能需求

### NFR-001：離線運作

PWA 必須透過 Service Worker 與 Cache API 支援離線運作。

### NFR-002：響應式設計

前端必須支援行動裝置與桌面的響應式設計。

### NFR-003：API 回應時間

API 對於已快取的查詢回應時間應低於 500ms。

### NFR-004：爬蟲速率限制

爬蟲應遵守 PTT 的速率限制，避免對伺服器造成負擔。

## 4. 使用案例

### UC-01：瀏覽最新梗圖

使用者開啟首頁，系統顯示最新爬取的梗圖清單。

### UC-02：搜尋梗圖

使用者輸入關鍵字，系統回傳相符的梗圖結果。

### UC-03：檢視原文

使用者點擊梗圖，系統導向 PTT 原文頁面。

### UC-04：離線瀏覽

使用者在無網路環境下仍可瀏覽先前已快取的梗圖。

### UC-05：自動更新內容

系統定時自動爬取新貼文，更新資料庫內容。

## 5. 範圍與限制

### 5.1 納入範圍 (In Scope)

- PTT Joke 板貼文爬取與儲存
- 圖片 URL 擷取與儲存（不下載圖片）
- REST API 提供貼文查詢
- PWA 前端顯示與搜尋
- 離線快取支援

### 5.2 排除範圍 (Out of Scope — MVP)

- 使用者帳號 / 登入系統
- 留言 / 投票功能
- 圖片代管服務
- 即時更新 (WebSocket)
- 推播通知 (Push Notification)

### 5.3 技術限制

- 僅使用 SQLite 作為資料庫（MVP 階段）
- 不下載或儲存圖片檔案
- 爬蟲僅針對 PTT Joke 板

## 6. Data Source Policy

### 6.1 公開資料原則

僅處理 PTT 公開可存取之內容。

### 6.2 存取限制

不要求使用者登入，不繞過任何存取限制。

### 6.3 圖片處理

不下載圖片，僅保存圖片 URL 供前端載入。

### 6.4 來源保留

保留 PTT article_url，供使用者返回原文出處。

## 7. Acceptance Criteria

### AC-FR-001：定時爬取

| 編號 | 驗收項目 |
|------|---------|
| AC-FR-001-1 | 爬蟲可成功連線至 PTT Joke 板 |
| AC-FR-001-2 | 爬蟲可定期自動執行爬取任務 |
| AC-FR-001-3 | 新貼文正確寫入資料庫 |

### AC-FR-002：擷取貼文資料

| 編號 | 驗收項目 |
|------|---------|
| AC-FR-002-1 | 標題正確擷取 |
| AC-FR-002-2 | 內文正確擷取 |
| AC-FR-002-3 | 圖片 URL 正確擷取 |
| AC-FR-002-4 | 文章連結正確擷取 |

### AC-FR-003：儲存資料

| 編號 | 驗收項目 |
|------|---------|
| AC-FR-003-1 | 資料庫中無圖片二進位資料 |
| AC-FR-003-2 | 相同 article_url + image_url 不重複寫入 |

### AC-FR-004：提供 REST API

| 編號 | 驗收項目 |
|------|---------|
| AC-FR-004-1 | `GET /api/posts` 回傳貼文列表 |
| AC-FR-004-2 | API 支援分頁參數 |
| AC-FR-004-3 | API 回傳正確 JSON 格式 |

### AC-FR-005：顯示梗圖

| 編號 | 驗收項目 |
|------|---------|
| AC-FR-005-1 | 首頁可以正常顯示最新梗圖 |
| AC-FR-005-2 | 圖片正確從 URL 載入顯示 |
| AC-FR-005-3 | 點擊可連結至 PTT 原文 |

### AC-FR-006：支援搜尋與篩選

| 編號 | 驗收項目 |
|------|---------|
| AC-FR-006-1 | 搜尋欄可輸入關鍵字 |
| AC-FR-006-2 | 搜尋結果正確過濾出符合條件的貼文 |

### AC-FR-007：離線瀏覽

| 編號 | 驗收項目 |
|------|---------|
| AC-FR-007-1 | Service Worker 成功註冊 |
| AC-FR-007-2 | 離線狀態下可顯示已快取內容 |
| AC-FR-007-3 | 離線時顯示適當的提示訊息 |
